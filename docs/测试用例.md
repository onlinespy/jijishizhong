# V1.0 功能测试用例

## 首次使用与断食

1. 首次进入断食设置，确认健康风险弹窗出现且未勾选时不能继续。
2. 勾选同意后进入模板页，退出再次进入时不再强制弹出。
3. 分别选择 16+8、14+10、18+6、5+2，确认说明和默认时间正确。
4. 修改进食开始与结束时间，确认进食与断食小时数同步变化。
5. 保存计划，返回首页确认时间轴、状态和倒计时正常。
6. 当日打卡一次，确认按钮变为“今日已打卡”，日历出现断食标记。
7. 点击“停止当前轻断食计划”，确认倒计时和打卡入口关闭，历史断食记录仍然保留。
8. 在计划设置页重新保存或启用，确认倒计时恢复且停止状态消失。

## 底部导航

1. 打开任意主页面，确认底部四个入口均有图标和文字，字号、对比度清晰。
2. 点击首页、记录、科普、我的，确认选中项切换为浅绿底、绿色图标和顶部指示条。
3. 使用 `wx.switchTab` 从快捷入口切换页面，确认自定义 TabBar 选中状态同步。

## 饮食与运动

1. 切换饮食四餐分类，保存记录后列表和当日总热量增加。
2. 从食物库选择米饭等支持“碗”的食物，切换克与碗时参考热量重新计算。
3. 输入食物名称，确认搜索结果按名称过滤，清空搜索后恢复当前分类。
4. 点击“复制昨日饮食”，确认昨日记录复制到当前日期并生成新记录 ID。
5. 手动填写食物名称、分量和参考热量，确认可以保存。
6. 未选食物或未填有效数量时，确认不能保存并提示。
7. 从运动库选择项目并填写时长，确认按档案体重估算消耗。
8. 档案体重为空时，确认运动库估算阻止保存并提示填写档案。
9. 自定义运动可填写名称、时长和参考消耗。
10. 删除饮食或运动记录后，列表和汇总立即更新。

## 体重与喝水

1. 输入有效体重并保存，确认历史列表、首页档案和 BMI 更新。
2. 同一天再次保存体重，确认更新原记录而不是新增重复日期。
3. 体重记录达到两次以上，确认趋势折线图正常显示。
4. 喝水目标只能设置为 1500 至 2500ml。
5. 点击 200/300/500ml 快捷按钮，确认总量和环形进度增加。
6. 喝水总量超过目标时，进度显示上限为 100%。
7. 点击“历史记录”，确认按日期查看每次喝水量与当日总量。
8. 在首页打开喝水提醒，确认必须经过微信订阅消息授权，拒绝后开关恢复关闭。
9. 点击首页“撤销上一次”，确认最近一次喝水记录被删除且进度同步回落。
10. 在喝水历史页点击单条“删除”，确认只删除目标记录，其他记录和总量正常更新。

## UI 规范回归

1. 所有主页面左右边距均为 16px，任何卡片和按钮不超出屏幕。
2. 所有卡片圆角为 12px、内边距为 16px、间距为 16px。
3. 主按钮高度为 44px，选项标签选中和未选中状态统一。
4. 页面只使用规范中的固定色值，不出现额外功能色。
5. 科普卡片固定高度一致，标题自动换行，不截断。
6. 四个底部 Tab 图标、文字大小、选中底色和间距完全一致。
7. 在食物分类、食物两列卡片和运动两列卡片中输入超长名称时，卡片不会被文字撑宽。
8. 真机页面用手指左右拖动时，页面不能跟随横向滚动。
9. 底部 Tab 上方最后一个卡片和按钮不能被遮挡或截断。
10. 选择白粥后，食用量输入框独占第一行，克/碗按钮位于输入框下方并等宽排列。
11. 食物卡片在 320px 至 430px 宽度范围内保持两列，文字不挤压、不横向溢出。
12. 食用量输入框独占第一行，克/碗按钮在第二行等宽排列，输入 `1000` 时全部字符可见。
13. 日历月份区始终为七列，日期格子保持正方形，月份切换后不横向溢出。

## 经期

1. 记录经期起止日期，确认保存成功。
2. 结束日期早于开始日期时，确认阻止提交。
3. 有历史记录时，确认可显示平均周期、下次经期、排卵日和易孕期预估。
4. 点击隐藏模块后，记录页不再显示经期页签。
5. 在个人档案中关闭隐藏开关后，经期页签恢复。

## 日历、勋章与设置

1. 在日历中切换月份，日期网格和标记正常更新。
2. 点击有记录日期，确认显示断食、喝水、体重、饮食热量、运动消耗或经期详情。
3. 完成连续记录后，确认勋章自动解锁，无积分或兑换入口。
4. 未配置订阅模板时开启提醒，确认提示先配置模板且开关恢复关闭。
5. 配置模板并接受授权后，确认订阅开关开启。
6. 拒绝授权后，确认开关保持关闭且不影响记录功能。
7. 清除全部记录需二次确认，清除后档案和计划保留。
8. 隐私政策和全局免责声明可以独立打开。

## 云开发

1. 部署云函数前，本地模式所有功能可用。
2. 部署后开启 `cloudEnabled`，确认云端首次拉取为空时写入本地数据。
3. 换设备或清缓存后，确认可以从云端拉取同一 OpenID 的记录。
4. 清除记录后，确认云端对应六类记录数组为空，档案和设置保留。
5. 订阅模板 ID 未配置时，定时提醒云函数不发送消息并返回跳过说明。

## 合规回归

1. 全页面搜索禁止话术，确认无“快速瘦”“减脂神器”“7天瘦身”等文案。
2. 热量、BMI、运动消耗页面只显示数字，不出现饮食好坏评价。
3. 经期与排卵结果均显示“预估参考”。
4. 每篇文章末尾都有统一科普免责声明。
5. 全局免责声明可通过“我的”和“设置”进入。
