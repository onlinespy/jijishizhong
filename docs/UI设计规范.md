# 记记食钟 UI 设计规范 V1.0

本规范是后续新增页面和功能迭代的固定约束。除产品负责人明确修改外，不得自行变更。

## 画布与页面结构

- 设计基准：微信小程序移动端，375px 宽度。
- 页面左右采用全屏流式布局，安全边距为 8px，即 WXSS `16rpx`；模块内部仍保留 16px 内容边距。
- 全局 `page` 使用 `width: 100vw`、`box-sizing: border-box` 和 `overflow-x: hidden`。
- 页面背景：`#FFFFFF`。
- 页面结构：顶部微信导航栏、页面主体、固定底部 TabBar。
- 底部四个 Tab 固定为：首页、记录、科普、我的，所有 Tab 页面保持一致。
- 所有模块和文字必须在左右安全边距内，不允许横向溢出。

## 自适应约束

- 页面、卡片、按钮、输入框统一 `width: 100%` 和 `box-sizing: border-box`。
- 所有 `flex` 子项统一 `min-width: 0 !important`，禁止内部文字反向撑宽容器。
- 所有文本容器使用 `word-break: break-all` 和 `overflow-wrap: anywhere`。
- 两列、三列、四列 Grid 统一使用 `minmax(0, 1fr)`。
- 禁止出现大于屏幕宽度的固定 `width` 或 `min-width`。
- 双列、三列和四列布局使用 `flex: 1` 或等分 Grid，不使用固定列宽。
- 食物分类、科普分类和记录双 Tab 全部使用全宽等分布局。
- 分类或列表不允许通过 `max-content`、负边距或超宽容器把页面撑开。
- TabBar 页面底部为固定导航预留 `168rpx + safe-area-inset-bottom`。

## 字体

| 类型 | 字号 | 字重 |
| --- | --- | --- |
| 页面大标题 | 18px / `36rpx` | 600 |
| 模块小标题 | 16px / `32rpx` | 500 |
| 正文 | 14px / `28rpx` | 400 |
| 辅助、备注、免责 | 12px / `24rpx` | 400 |

重点数字可使用 `40rpx` 至 `56rpx` 主色数字。所有文字自动换行，不截断、不溢出。

## 卡片

- 圆角：12px / `24rpx`
- 卡片本身左右 padding 为 0，仅保留上下 `32rpx`；左右内容间距由卡片第一层子组件控制为 `16rpx`，避免与页面安全边距叠加。
- 描边：`#EEEEEE`
- 阴影：`0 4rpx 16rpx rgba(0, 0, 0, 0.04)`
- 卡片间距：16px / `32rpx`
- 同类卡片尺寸统一，不允许忽大忽小。

## 按钮

- 主按钮：44px / `88rpx` 高，8px / `16rpx` 圆角，主色背景，白色文字。
- 选项标签：8px / `16rpx` 圆角；选中为主色背景和白色文字；未选中为白色背景、主色描边和灰色文字。
- 标签间距：8px / `16rpx`。

## 页面规则

- 首页顺序：轻断食计划、喝水记录、摄入与运动并排卡、热量差额、免责提示。
- 喝水记录标题在左，目标和历史记录在右；环形进度居中；三个水量按钮使用三等分全宽布局。
- 记录页顶部只保留“饮食｜运动”双 Tab，体重与经期作为次级入口。
- 饮食支持食物搜索、复制昨日饮食以及按克数或碗数计算热量。
- 食用量使用上下两行：第一行为全宽输入框，第二行为等宽“克 / 碗”切换按钮。
- 食用量区固定使用 `food-input-row / gram-input / unit-switch / unit-btn`，输入框高度 `96rpx`，单位按钮高度 `80rpx`。
- 喝水支持撤销最近一次记录，并可在历史页逐条删除误触记录。
- 科普标签与记录页标签样式一致，文章卡片固定统一高度。
- 我的页面功能行统一高度、图标尺寸和分割线样式。
- 日历、勋章、档案、设置、协议、喝水历史和其他新增页面全部沿用本规范。
- 日历月份区固定使用 `calendar-grid / calendar-day`，七列宽度为 `calc((100% - 72rpx) / 7)`，格子保持 `aspect-ratio: 1`。
