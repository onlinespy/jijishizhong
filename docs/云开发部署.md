# 微信云开发部署

## 1. 创建环境

1. 使用个人主体注册并认证微信小程序。
2. 在微信开发者工具中打开项目，点击顶部“云开发”。
3. 新建云环境，记录环境 ID，例如 `health-prod-xxxxx`。
4. 建议先创建开发环境和正式环境，避免测试数据与上线数据混用。

## 2. 创建数据库

创建集合：

```text
health_profiles
```

推荐权限：

```text
仅云函数可读写
```

数据结构为一个微信用户一条文档，由 `_openid` 隔离。文档包含健康档案、断食计划、六类记录和提醒设置。

## 3. 部署云函数

在微信开发者工具中依次操作：

1. 右键 `cloudfunctions/login`，选择“上传并部署：云端安装依赖”。
2. 右键 `cloudfunctions/health`，选择“上传并部署：云端安装依赖”。
3. 右键 `cloudfunctions/sendReminders`，选择“上传并部署：云端安装依赖”。

`sendReminders/config.json` 已配置两个定时触发器：

```text
每天 09:00 检查经期提醒
每天 19:00 检查喝水提醒
```

云函数会根据用户是否主动授权、是否已经完成记录决定是否发送。订阅消息属于一次性授权时，成功发送后会将对应开关改回关闭，用户下次需要再次授权。

## 4. 配置订阅消息模板

在微信公众平台进入“功能-订阅消息”：

1. 添加喝水提醒和经期提醒模板。
2. 记录模板 ID。
3. 根据模板实际字段修改 `cloudfunctions/sendReminders/index.js` 中的 `data` 字段。
4. 在云函数配置中增加环境变量：

```text
WATER_TEMPLATE_ID=模板ID
PERIOD_TEMPLATE_ID=模板ID
```

5. 编辑 `miniprogram/config/index.js`：

```js
subscriptionTemplates: {
  water: '喝水模板ID',
  period: '经期模板ID'
}
```

模板字段名称必须与代码一致。若公众平台生成的是 `thing1`、`time2`、`date1` 之外的其他字段，需要同步调整云函数发送参数。

## 5. 启用云同步

修改：

```js
cloudEnabled: true,
cloudEnv: '你的环境ID',
cloudFunctionName: 'health',
```

重新编译后，下拉首页会尝试拉取云端数据。云端为空时会把当前本地数据写入云数据库。

## 6. 上线前检查

- 将 `project.config.json` 的 `appid` 改为真实 AppID。
- 将 `demoDataEnabled` 改回 `false`。
- 删除演示数据。
- 在开发版和体验版分别验证云同步、隐私协议、订阅授权和记录清理。
- 在公众平台配置隐私保护指引，声明健康档案与打卡记录用途。
- 检查类目为“生活服务-健康养生工具”，不要选择医疗类目。
